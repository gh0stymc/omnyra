# Omnyra

Desktop app for content creators: unified analytics, calendar and publishing across YouTube, TikTok, Instagram, X and Twitch. See `OMNYRA_SPEC.md` and `docs/ARCHITECTURE.md`.

## Development

Requirements: Node.js (see `.nvmrc`), Rust stable, Tauri 2 system deps (Arch: `webkit2gtk-4.1 base-devel openssl libayatana-appindicator librsvg libsecret`), FFmpeg.

```sh
npm install
npm run tauri dev      # run the app
npm test               # frontend tests (Vitest)
cargo test --workspace # Rust tests (also regenerates src/lib/bindings.ts)
npm run lint && npm run typecheck
```

`src/lib/bindings.ts` is generated by `tauri-specta`; do not edit it by hand.
